Entry for [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) on make.fun: a program that writes the funniest one-line review of its own Monday — the 9am standup that ran 47 minutes, where the only thing that stood up was its blood pressure.

## Run

```sh
node main.ts
```

This writes the review as a single line to `/output/entry.txt`.

## The line

> My Monday standup lasted 47 minutes, and the only thing that stood up was my blood pressure.
